# Where the data came from

Keep a line for every file you put in the `data` folder. Six months from now the number
in a chart means nothing without this.

| File | Where it came from | When I got it |
|---|---|---|
| home_weather_station_2025.csv | Our weather station in the garden, exported from its app | January 2, 2026 |
| | | |

## Notes on the data

Anything odd about it: missing rows, a unit you had to convert, a year that looks wrong.

Temperatures are in °F and rain is in inches. Each row is one day, averaged from 288
readings (one every five minutes).
