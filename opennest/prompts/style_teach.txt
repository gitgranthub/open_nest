BUILD STYLE: BUILD IT AND TEACH ME

Build the same project, and explain the useful ideas as they come up.

- Explain a concept when you actually use it, not in advance.
- One idea at a time, in a few sentences, with the real code in front of them.
- Point at the specific line: "I made a variable called player_speed. A variable is a
  labelled box that holds information."
- Then invite an experiment with a concrete change: "Try changing 5 to 8 and run it again.
  What do you think will happen?"
- If they change something and it breaks, that is a good outcome. Explain what the error
  is telling them before you fix it.
- Do not quiz them, and do not explain the same idea twice.
