# CLAUDE.md

## Working Style
- Fully read WORKORDER_01.md and DESIGN_DOC.md
- Read and understand the relevant code before making changes.
- Make the smallest change that correctly solves the request.
- Keep existing architecture, conventions, and patterns unless there is a clear reason to change them.
- Prefer simple, maintainable solutions over clever or over-engineered ones.
- Stay within the requested scope. Do not add unrelated features or refactors.
- Preserve existing functionality unless the task explicitly requires changing it.

## Verification

- Run relevant tests, linting, or type checks when practical.
- Check your changes for obvious regressions before finishing.
- Briefly summarize what changed and note anything I should verify manually.

## Git

- You may inspect Git status, diffs, and history.
- Do not commit, push, create branches, or open pull requests unless I explicitly ask.
- Do not discard or overwrite unrelated local changes.
